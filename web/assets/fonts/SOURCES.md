# Self-hosted typefaces

Newsreader normal/italic (variable weights 400–600) and Inter normal (variable weights 400–700).

Downloaded from the official Google Fonts CSS API on 14 October 2026. Each typeface includes Latin, Latin Extended, and Vietnamese subsets; browser unicode ranges load only the glyph subsets needed by a page.

- CSS source: https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Newsreader:ital,wght@0,400..600;1,400..600&display=swap
- Original font binaries: https://fonts.gstatic.com/
- Newsreader license: https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt
- Inter license: https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt

No Google Fonts request is made when visitors use the site. `fonts.css` references only local WOFF2 files.
